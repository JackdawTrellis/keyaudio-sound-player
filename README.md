## ⌨️ KeyAudio Sound Player — Keyboard Sound Simulator

**KeyAudio Sound Player** simulates mechanical keyboard sounds for any keyboard. Choose from Cherry MX, Topre, ALPS, and custom sound packs.

---

## ✨ Features

- 🎵 30+ built-in mechanical keyboard sound profiles
- 🔊 Per-key customization (unique sounds per key)
- 🎛️ Volume, pitch, and reverb controls
- ⚡ Ultra-low latency (< 5ms)
- 🔇 System tray — runs silently in the background
- 📦 No drivers required — works with any keyboard

---

## 🛠️ Installation

```
1. Download the setup below
2. Run KeyAudioSoundPlayerSetup.exe
3. Choose sound profile
4. Toggle with hotkey (default: Ctrl+Shift+K)
```
